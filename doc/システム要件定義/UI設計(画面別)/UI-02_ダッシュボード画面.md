# UI-02 ダッシュボード(月報一覧)画面

## 1. 画面概要

- 画面ID: UI-02
- 画面名: ダッシュボード(月報一覧)
- 目的: 月報の一覧閲覧と詳細遷移、作成遷移。TL以上は未提出者モニタリングと提出率も確認できる。

## 2. 表示エリア

- ヘッダ(固定): ユーザー名、社員番号、所属、ロール、月報ナビ、エスカレーションナビ(TL以上)、ログアウト
- 提出期限バナー(ヘッダ直下固定): 残日数・自分の提出有無
- KPI: 今月提出完了率・未回答報告数(TL以上のみ表示)
- 未提出者モニタリング: 未提出メンバーのチップ一覧(TL以上のみ表示)
- 操作: 新規提出ボタン
- 一覧: 月報カード(タイトル、月、提出者、回答状態)

## 3. 表示制御

- REPORTER（メンバー）: 自分の月報のみ
- TL: 自分 + 同一チーム
- GL: 自分 + 同一営業所
- OM: 全件

## 4. 提出期限バナー仕様

- 全ロール共通で表示する。
- 今月 (YYYY-MM) の残日数 = 締切日 (毎月5日) - 今日
- 自分が今月分を提出済みか否かで表示を切り替える。
  - 未提出: 警告表示（赤系バッジ、点滅）
  - 提出済み: 完了表示（緑系バッジ）

## 5. 未提出者モニタリング仕様 (TL以上)

- ロール別スコープ内のメンバー（REPORTER のみ対象）を今月提出済みかで判定。
- 未提出者をチップ形式で表示。全員提出済みの場合は完了メッセージを表示。
- 今月提出完了率 (%) とプログレスバーを表示。

## 6. イベント

- 新規提出押下 → 月報作成画面へ
- カード押下 → 月報詳細画面へ
- エスカレーション押下 → エスカレーション一覧画面へ (TL以上のみ)
- ログアウト押下 → セッション破棄、ログイン画面へ

## 7. API連携

- `POST /api/v1/users/me`
- `POST /api/v1/dashboard/summary`
- `POST /api/v1/reports/search`
- `POST /api/v1/auth/logout`

## 8. 一覧項目

| 項目 | 説明 |
|---|---|
| month | 報告月 |
| title | タイトル |
| reporterName | 提出者名 |
| feedbackRegistered | 回答有無 (`Checked` / `Waiting`) |
| updatedAt | 最終更新日時 |

## 9. 例外時

- 一覧0件: 空状態メッセージを表示
- APIエラー: インターセプターが throw した `error.message`（= `resultMsg`）をトーストで表示
- HTTP 401: axios インターセプターが `localStorage` の `authToken` を削除し、自動でログイン画面へ遷移する（画面層の個別対応不要）
