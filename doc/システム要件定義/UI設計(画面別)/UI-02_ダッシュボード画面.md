# UI-02 ダッシュボード(月報一覧)画面

## 1. 画面概要

- 画面ID: UI-02
- 画面名: ダッシュボード(月報一覧)
- 目的: 月報の一覧閲覧と詳細遷移、作成遷移。TL以上は未提出者モニタリングと提出率も確認できる。
- アクセス可能ロール: **NG を除く全ロール**

### 提出期限バナー仕様（全ロール共通）

- ヘッダ直下に固定表示する。
- 今月（YYYY-MM）の残日数 = 締切日（毎月5日）- 今日
- 自分が今月分を提出済みの場合は完了表示（緑系バッジ）、未提出の場合は警告表示（赤系バッジ）

### 未提出者モニタリング（TL以上のみ）

- ロール別スコープ内のメンバー（TM のみ対象）を今月提出済みかで判定する。
- 未提出者をチップ形式で表示し、全員提出済みの場合は完了メッセージを表示する。
- 今月提出完了率（%）とプログレスバーを表示する。

## 2. 入力項目

| 項目ID | 項目名 | 必須 | 形式 | 備考 |
|---|---|---|---|---|
| DB-F01 | 月フィルター | N | text / select | `yyyy-MM` 形式 |
| DB-F02 | ステータスフィルター | N | select | ALL / SUBMITTED / PENDING_FEEDBACK / FEEDBACKED |

### 一覧表示項目

| 項目 | 説明 |
|---|---|
| month | 報告月 |
| reporterName | 提出者名 |
| feedbackRegistered | 回答有無（`Checked` / `Waiting`） |
| updatedAt | 最終更新日時 |

## 3. ボタン

| ボタンID | ボタン名 | 動作 |
|---|---|---|
| DB-B01 | 新規提出 | 月報作成画面（UI-03）へ遷移 |
| DB-B02 | ログアウト | セッション破棄、ログイン画面へ遷移 |
| DB-B03 | エスカレーション | エスカレーション画面（UI-05）へ遷移（TL以上のみ表示） |

## 4. イベント

- **画面初期表示**
  1. `POST /api/v1/users/me` でユーザー情報を取得する
  2. `POST /api/v1/dashboard/summary` で集計データを取得し、KPI・未提出者を表示する
  3. `POST /api/v1/reports/search` で月報一覧を取得する
- **月報カード押下** → 月報詳細画面（UI-04）へ遷移
- **新規提出押下** → 月報作成画面（UI-03）へ遷移
- **エスカレーション押下** → エスカレーション画面（UI-05）へ遷移（TL以上のみ表示）
- **ログアウト押下** → `POST /api/v1/auth/logout` → `localStorage` から `authToken` を削除 → ログイン画面へ遷移
- **APIエラー発生時** → インターセプターが throw した `error.message`（= `resultMsg`）をトーストで表示

## 5. API連携

- `POST /api/v1/users/me`
- `POST /api/v1/dashboard/summary`
- `POST /api/v1/reports/search`
- `POST /api/v1/auth/logout`

## 6. 入力チェック

| 項目 | ルール |
|---|---|
| 月フィルター | 任意。指定時は `yyyy-MM` 形式 |
| ステータスフィルター | 任意。列挙値のみ許可 |

## 7. 画面制御

| 要素 | 表示条件 |
|---|---|
| 新規提出ボタン | 全ロール（NG は非表示） |
| エスカレーションナビ | TL 以上のみ表示 |
| KPI（提出率・未提出者モニタリング） | TL 以上のみ表示 |
| 月報一覧スコープ | NG = アクセス不可 / TM = 自分のみ / TL = 自分+同一チーム / GL = 自分+同一営業所 / OM = 全件 |
