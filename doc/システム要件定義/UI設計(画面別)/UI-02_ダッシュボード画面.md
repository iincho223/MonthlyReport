# UI-02 ダッシュボード(月報一覧)画面

## 1. 画面概要
- 画面ID: UI-02
- 画面名: ダッシュボード(月報一覧)
- 目的: 月報の一覧閲覧と詳細遷移、作成遷移

## 2. 表示エリア
- ヘッダ: ユーザー名、社員番号、所属、ロール、ログアウト
- KPI: 管理内全提出数、未回答報告数(TL以上のみ)
- 操作: 新規提出ボタン
- 一覧: 月報カード(タイトル、月、提出者、回答状態)

## 3. 表示制御
- REPORTER: 自分の月報のみ
- TL: 自分 + 同一チーム
- GL: 自分 + 同一営業所
- OM: 全件

## 4. イベント
- 新規提出押下 -> 月報作成画面へ
- カード押下 -> 月報詳細画面へ
- ログアウト押下 -> セッション破棄、ログイン画面へ

## 5. API連携
- `POST /api/v1/users/me`
- `POST /api/v1/dashboard/summary`
- `POST /api/v1/reports/search`
- `POST /api/v1/auth/logout`

## 6. 一覧項目
| 項目 | 説明 |
|---|---|
| month | 報告月 |
| title | タイトル |
| reporterName | 提出者名 |
| feedbackRegistered | 回答有無 (`Checked/Waiting`) |
| updatedAt | 最終更新日時 |

## 7. 例外時
- 一覧0件: 空状態メッセージを表示
- APIエラー: トーストで `resultMsg` を表示
