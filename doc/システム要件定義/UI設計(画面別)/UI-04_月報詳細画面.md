# UI-04 月報詳細画面

## 1. 画面概要

- 画面ID: UI-04
- 画面名: 月報詳細
- 目的: 月報の詳細表示、回答登録、編集/削除導線
- アクセス可能ロール: **NG を除く全ロール**（参照スコープ外は 403）

## 2. 入力項目

| 項目ID | 項目名 | 必須 | 形式 | 備考 |
|---|---|---|---|---|
| RD-01 | 月 | - | 表示のみ | 報告月 |
| RD-02 | 営業所 | - | 表示のみ | - |
| RD-03 | チーム | - | 表示のみ | - |
| RD-04 | 提出者情報 | - | 表示のみ | 氏名・社員番号・ロール |
| RD-05 | 営業情報 | - | 表示のみ | - |
| RD-06 | 来月残業見込み | - | 表示のみ | 数値＋理由 |
| RD-07 | 今月残業見込み | - | 表示のみ | 数値＋理由 |
| RD-08 | コンディション自己診断 | - | 表示のみ | 7項目バッジ表示 |
| RD-09 | コメント | - | 表示のみ | - |
| RD-10 | フィードバックコメント | Y（回答時） | textarea | TL以上かつ他者月報のみ入力可 |

## 3. ボタン

| ボタンID | ボタン名 | 表示条件 |
|---|---|---|
| RD-B01 | 編集 | 作成者本人のみ |
| RD-B02 | 削除 | 作成者本人 または OM |
| RD-B03 | 回答公開 | TL以上かつ他者月報のみ |

## 4. イベント

- **画面初期表示**
  1. `POST /api/v1/reports/detail` でデータを取得する
  2. 取得データを各表示項目にバインドする
- **回答公開押下**
  1. `POST /api/v1/reports/feedback/update` を実行する
  2. 成功時に回答表示を更新する（トースト表示）
- **削除押下**
  1. 確認ダイアログを表示する
  2. `POST /api/v1/reports/delete` を実行する
  3. 成功時にダッシュボード画面（UI-02）へ遷移する
- **編集ボタン押下** → 月報作成/編集画面（UI-03）へ遷移（編集モード）

## 5. API連携

- `POST /api/v1/reports/detail`
- `POST /api/v1/reports/feedback/update`
- `POST /api/v1/reports/delete`

## 6. 入力チェック

| 項目 | ルール | エラーメッセージ |
|---|---|---|
| フィードバックコメント | 必須（回答時）、最大2000文字 | コメントを入力してください |

## 7. 画面制御

| 要素 | 表示/活性条件 |
|---|---|
| 編集ボタン | 作成者本人のみ表示 |
| 削除ボタン | 作成者本人、または OM のみ表示 |
| 回答入力欄・回答公開ボタン | TL以上かつ他者月報のみ表示 |
| 回答表示エリア | 全ロール表示（回答未登録の場合は非表示） |
| 回答公開ボタン活性 | フィードバックコメント入力済みの場合のみ活性 |
