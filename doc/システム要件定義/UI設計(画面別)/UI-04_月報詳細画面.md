# UI-04 月報詳細画面

## 1. 画面概要
- 画面ID: UI-04
- 画面名: 月報詳細
- 目的: 月報詳細表示、回答登録、編集/削除導線

## 2. 表示項目
- ヘッダ: 月、営業所、チーム、提出者情報
- 本文: 営業情報、残業見込み、コンディション、コメント
- 回答欄: 管理者回答の表示/入力
- 操作: 編集、削除、回答公開

## 3. 表示/操作制御
- 編集ボタン: 作成者本人のみ
- 削除ボタン: 作成者本人 or OM
- 回答入力/公開: TL以上かつ他者月報
- 回答表示: 全ロール

## 4. イベント
- 画面表示時
1. `POST /api/v1/reports/detail`
2. 取得データを表示
- 回答公開押下
1. `POST /api/v1/reports/feedback/update`
2. 成功時に回答表示を更新
- 削除押下
1. 確認ダイアログ
2. `POST /api/v1/reports/delete`
3. 一覧へ遷移

## 5. API連携
- `POST /api/v1/reports/detail`
- `POST /api/v1/reports/feedback/update`
- `POST /api/v1/reports/delete`

## 6. メッセージ
- 回答保存成功: 「回答を保存しました」
- 削除成功: 「削除しました」
- 権限エラー: 「権限がありません」

## 7. プロトタイプ準拠ポイント
- 回答有無に応じた表示切替
- 回答者ロール/氏名表示
- 本文セクションのカード表示
