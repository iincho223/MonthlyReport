# UI-01 ログイン画面

## 1. 画面概要

- 画面ID: UI-01
- 画面名: ログイン画面
- 目的: 社員番号/パスワードで認証する

## 2. レイアウト

- 中央カードレイアウト
- 入力欄: 社員番号、パスワード
- 主ボタン: ログイン
- 補助表示: エラーメッセージ

## 3. 項目定義

| 項目ID | 項目名 | 種別 | 必須 | 形式 | 備考 |
|---|---|---|---|---|---|
| LG-01 | 社員番号 | input text | Y | 半角英数 | 例: EMP001 |
| LG-02 | パスワード | input password | Y | 文字列 | マスク表示 |
| LG-03 | ログイン | button | - | - | API実行 |
| LG-04 | エラー表示 | label | - | - | 認証失敗時 |

## 4. イベント

- `LG-03` 押下

1. 入力チェック
2. `POST /api/v1/auth/login`
3. 成功時: ダッシュボード遷移
4. 失敗時: `resultMsg` を表示

## 5. バリデーション

- 社員番号: 必須、英数字
- パスワード: 必須

## 6. API連携

- `POST /api/v1/auth/login`

## 7. メッセージ例

- 認証失敗: 「社員番号またはパスワードが正しくありません」
- 通信失敗: 「通信エラーが発生しました」
