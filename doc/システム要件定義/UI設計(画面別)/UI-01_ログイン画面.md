# UI-01 ログイン画面

## 1. 画面概要

- 画面ID: UI-01
- 画面名: ログイン画面
- 目的: 社員番号/パスワードで認証し、ダッシュボードへ遷移する
- アクセス可能ロール: **全員**（未認証ユーザーを含む）
- レイアウト: 中央カードレイアウト

## 2. 入力項目

| 項目ID | 項目名 | 必須 | 形式 | 備考 |
|---|---|---|---|---|
| LG-01 | 社員番号 | Y | input text | 半角英数、例: EMP001 |
| LG-02 | パスワード | Y | input password | マスク表示 |

## 3. ボタン

| ボタンID | ボタン名 | 動作 |
|---|---|---|
| LG-03 | ログイン | 入力チェック後、API 実行 |

## 4. イベント

- `LG-03`（ログイン）押下

  1. 入力チェック（社員番号・パスワード必須）
  2. `POST /api/v1/auth/login` を実行する（axios インスタンス経由）
  3. 成功時: `params.accessToken` を `localStorage` の `authToken` キーに保存する
  4. `params.userProfile` の内容でユーザー情報を初期化し、ダッシュボードへ遷移する
  5. 失敗時: インターセプターが throw した `error.message`（= `resultMsg`）を LG-04 (エラーラベル) に表示する

## 5. API連携

- `POST /api/v1/auth/login`

## 6. 入力チェック

| 項目 | ルール | エラーメッセージ |
|---|---|---|
| 社員番号 | 必須、半角英数字 | 社員番号を入力してください |
| パスワード | 必須 | パスワードを入力してください |
| 認証失敗 | API エラー | 社員番号またはパスワードが正しくありません |

## 7. 画面制御

- ログインボタンは社員番号・パスワードの両方が入力済みの場合のみ活性とする。
- 認証成功後はダッシュボードへリダイレクトし、ログイン画面には戻れないようにする。
- ログイン API は未認証リクエストのため `Authorization` ヘッダは付与しない（axios インターセプターの仕様による）。
