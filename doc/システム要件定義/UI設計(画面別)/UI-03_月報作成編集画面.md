# UI-03 月報作成/編集画面

## 1. 画面概要

- 画面ID: UI-03
- 画面名: 月報作成/編集
- 目的: 月報の新規登録/更新

## 2. 入力項目

| 項目ID | 項目名 | 必須 | 形式 | 備考 |
|---|---|---|---|---|
| RP-01 | 報告月 | Y | yyyy-MM | |
| RP-02 | タイトル | Y | 最大100 | |
| RP-03 | 営業情報 | N | text | |
| RP-04 | 来月残業見込み | N | 0-300 | 単位h |
| RP-05 | 来月残業理由 | N | 最大255 | |
| RP-06 | 今月残業見込み | N | 0-300 | 単位h |
| RP-07 | 今月残業理由 | N | 最大255 | |
| RP-08 | コンディション7項目 | Y | `◎/○/▲/×` | APIでは `BEST/GOOD/WARN/NG` |
| RP-09 | コメント | N | text | |

## 3. ボタン

- `提出/保存`: 新規時は作成API、編集時は更新API
- `キャンセル`: ダッシュボードへ戻る

## 4. イベント

- 画面表示時
  - 編集モードなら `POST /api/v1/reports/detail` で値を初期表示
- 保存押下
  1. 入力チェック
  2. 新規: `POST /api/v1/reports/create`
  3. 編集: `POST /api/v1/reports/update`
  4. 成功時トースト表示後、一覧へ遷移

## 5. API連携

- `POST /api/v1/reports/detail` (編集時のみ)
- `POST /api/v1/reports/create`
- `POST /api/v1/reports/update`

## 6. 入力チェック

- タイトル必須
- 時間項目は数値かつ0-300
- コンディション7項目は必須

## 7. 画面制御

- タイトル未入力時は保存ボタン無効
- API実行中は保存ボタン無効
