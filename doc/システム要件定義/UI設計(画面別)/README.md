# UI設計(画面別) 一覧

## 1. 目的

本ディレクトリは、`UI設計書.md` を画面単位に分解した詳細設計を管理する。

## 2. 対象画面

- UI-01: ログイン画面
- UI-02: ダッシュボード(月報一覧)画面
- UI-03: 月報作成/編集画面
- UI-04: 月報詳細画面
- UI-05: エスカレーション管理画面（TL以上）
- UI-06: ユーザー管理画面（GL/OM/SP/SM/SA）
- UI-07: 組織管理画面（GL/OM/SA）

## 3. 設計方針

- `doc/画面要件/画面要件.html` の動作を基準とする。
- APIは `POST /api/v1/*` を利用する。
- 全 API 通信は axios インスタンス経由で行う（`fetch` / `XMLHttpRequest` 禁止）。
  - 認証ヘッダはリクエストインターセプターが自動付与する。
  - エラー・セッション切れ（401）はレスポンスインターセプターが公共実装する。
  - 詳細は `UI設計書.md` の 5.7 節を参照。
- ロール別の表示・操作制御を画面仕様に明記する。
