# UI-07 組織管理画面

## 1. 画面概要

| 項目 | 内容 |
|---|---|
| 画面 ID | UI-07 |
| 画面名 | 組織管理画面 |
| 表示対象ロール | GL・OM・SA |
| URL（プロトタイプ） | `#org-management` |
| 概要 | グループ・チームの一覧表示・新規登録・削除を行う画面。GL はチームのみ操作可能でグループの作成・削除は OM/SA のみ。 |

---

## 2. 入力項目

### 2.1 グループ検索フォーム

| 項目名 | 型 | 必須 | 説明 |
|---|---|---|---|
| グループ名 | text | 任意 | 部分一致検索 |
| 営業所 | select | 任意 | 営業所コードで絞り込み（SA のみ表示） |

### 2.2 グループ登録フォーム（OM・SA のみ表示）

| 項目名 | 型 | 必須 | 説明 |
|---|---|---|---|
| グループコード | text | 必須 | 英数字アンダースコア、最大32文字、一意 |
| グループ名 | text | 必須 | 最大100文字 |
| 営業所 | select | 必須 | - |
| GL ユーザー | select | 必須 | グループリーダーに指定するユーザー |

### 2.3 チーム検索フォーム

| 項目名 | 型 | 必須 | 説明 |
|---|---|---|---|
| チーム名 | text | 任意 | 部分一致検索 |
| グループ | select | 任意 | グループコードで絞り込み |

### 2.4 チーム登録フォーム

| 項目名 | 型 | 必須 | 説明 |
|---|---|---|---|
| チームコード | text | 必須 | 英数字アンダースコア、最大32文字、一意 |
| チーム名 | text | 必須 | 最大100文字 |
| グループ | select | 必須 | 所属グループを選択 |
| TL ユーザー | select | 必須 | チームリーダーに指定するユーザー |

---

## 3. ボタン

| ボタン名 | 配置 | アクション |
|---|---|---|
| グループ検索 | グループ検索フォーム右端 | グループ一覧を再取得（API-20） |
| グループ登録 | グループ登録フォーム右端 | グループを新規登録（API-21）。OM/SA のみ表示 |
| グループ削除 | グループ一覧行末尾 | 対象グループを削除（API-22）。確認ダイアログを表示してから実行。OM/SA のみ表示 |
| チーム検索 | チーム検索フォーム右端 | チーム一覧を再取得（API-23） |
| チーム登録 | チーム登録フォーム右端 | チームを新規登録（API-24） |
| チーム削除 | チーム一覧行末尾 | 対象チームを削除（API-25）。確認ダイアログを表示してから実行 |

---

## 4. イベント

| イベント | トリガー | 処理概要 |
|---|---|---|
| 画面初期表示 | mounted | ロール確認 → アクセス不可なら Dashboard へリダイレクト。グループ一覧（API-20）・チーム一覧（API-23）を取得 |
| グループ検索実行 | グループ検索ボタンクリック | 検索条件を組み立てて API-20 を呼び出し、グループ一覧を更新 |
| グループ登録実行 | グループ登録ボタンクリック | 入力チェック → API-21 → 成功時はフォームをクリアしてグループ一覧を再取得 |
| グループ削除実行 | グループ削除ボタンクリック | 確認ダイアログ → OK 時に API-22 → 成功時はグループ一覧を再取得 |
| チーム検索実行 | チーム検索ボタンクリック | 検索条件を組み立てて API-23 を呼び出し、チーム一覧を更新 |
| チーム登録実行 | チーム登録ボタンクリック | 入力チェック → API-24 → 成功時はフォームをクリアしてチーム一覧を再取得 |
| チーム削除実行 | チーム削除ボタンクリック | 確認ダイアログ → OK 時に API-25 → 成功時はチーム一覧を再取得 |

---

## 5. API連携

| API ID | エンドポイント | 用途 |
|---|---|---|
| API-20 | `POST /api/v1/groups/search` | グループ一覧取得 |
| API-21 | `POST /api/v1/groups/create` | グループ登録 |
| API-22 | `POST /api/v1/groups/delete` | グループ削除 |
| API-23 | `POST /api/v1/teams/search` | チーム一覧取得 |
| API-24 | `POST /api/v1/teams/create` | チーム登録 |
| API-25 | `POST /api/v1/teams/delete` | チーム削除 |

---

## 6. 入力チェック

| 項目 | チェック内容 |
|---|---|
| グループコード | 必須・英数字アンダースコア・最大32文字 |
| グループ名 | 必須・最大100文字 |
| 営業所（グループ） | 必須 |
| GL ユーザー | 必須 |
| チームコード | 必須・英数字アンダースコア・最大32文字 |
| チーム名 | 必須・最大100文字 |
| グループ（チーム） | 必須 |
| TL ユーザー | 必須 |

---

## 7. 画面制御

| 制御対象 | 条件 | 制御内容 |
|---|---|---|
| 組織管理画面全体 | ロールが GL/OM/SA 以外 | 画面表示不可。ダッシュボードへリダイレクト |
| グループ登録フォーム | ロールが GL | 非表示（GL はグループ作成不可） |
| グループ削除ボタン | ロールが GL | 非表示（GL はグループ削除不可） |
| 営業所フィルター（グループ検索） | ロールが GL/OM | 非表示（自営業所固定） |
| GL ユーザー選択肢 | - | 自スコープ内のユーザーのみ選択可 |
| TL ユーザー選択肢 | - | 選択グループ配下のユーザーのみ選択可 |
