# UI-05 エスカレーション管理画面

## 1. 画面概要
- 画面ID: UI-05
- 画面名: エスカレーション管理
- 目的: チーム・営業所内でのトラブル/案件を起票・管理し、対応履歴を追跡する
- アクセス可能ロール: **TL・GL・OM のみ**（REPORTER はアクセス不可）

---

## 2. サブ画面構成
| サブID | 名称 | 概要 |
|---|---|---|
| UI-05-1 | エスカレーション一覧 | 可視範囲内の案件カード一覧 |
| UI-05-2 | エスカレーション作成/編集 | 新規起票・内容変更フォーム |
| UI-05-3 | エスカレーション詳細 | 詳細情報・履歴タイムライン・ログ追記 |

---

## 3. UI-05-1 エスカレーション一覧

### 表示項目
| 項目ID | 項目名 | 種別 | 備考 |
|---|---|---|---|
| ES-01 | ステータスバッジ | バッジ | PENDING(赤)/ONGOING(青)/RESOLVED(緑) |
| ES-02 | 重要度 | ラベル | LOW(グレー)/MEDIUM(黄)/HIGH(赤) |
| ES-03 | 案件タイトル | テキスト | |
| ES-04 | 対象メンバー氏名 | テキスト | |
| ES-05 | 担当者名(起票者) | テキスト | |
| ES-06 | 新規起票ボタン | ボタン | TL以上のみ |

### 表示制御(ロール)
- TL: 自チームに関するもの + 自分が起票したもの
- GL: 自営業所のもの全件
- OM: 全件

### イベント
- 新規起票押下 → UI-05-2（新規モード）
- カード押下 → UI-05-3

### API連携
- `POST /api/v1/escalations/search`

---

## 4. UI-05-2 エスカレーション作成/編集

### 入力項目
| 項目ID | 項目名 | 必須 | 形式 | 備考 |
|---|---|---|---|---|
| EF-01 | 対象メンバー氏名 | Y | text | 自由入力 |
| EF-02 | 所属チーム | Y | 選択 | チームマスタより |
| EF-03 | 案件タイトル | Y | 最大200 | |
| EF-04 | 重要度 | Y | 選択 | LOW/MEDIUM/HIGH |
| EF-05 | ステータス | Y | 選択 | PENDING/ONGOING/RESOLVED |
| EF-06 | 詳細内容 | N | text | テキストエリア |

### ボタン
- `起票/保存`: 新規時は作成API、編集時は更新API
- `キャンセル`: 一覧へ戻る

### イベント
- 保存押下
  1. 入力チェック（案件タイトル必須）
  2. 新規: `POST /api/v1/escalations/create`
  3. 編集: `POST /api/v1/escalations/update`
  4. 成功時トースト表示後、一覧へ遷移

### API連携
- `POST /api/v1/escalations/create`
- `POST /api/v1/escalations/update`

---

## 5. UI-05-3 エスカレーション詳細

### 表示項目
| 項目ID | 項目名 | 種別 | 備考 |
|---|---|---|---|
| ED-01 | ステータスバッジ | バッジ | PENDING/ONGOING/RESOLVED |
| ED-02 | 重要度 | ラベル | LOW/MEDIUM/HIGH |
| ED-03 | 案件タイトル | テキスト | |
| ED-04 | 対象メンバー/チーム | ラベル | |
| ED-05 | 詳細内容 | 表示領域 | whitespace-pre-wrap |
| ED-06 | 対応履歴タイムライン | リスト | 日時・記録者・内容（新旧順） |
| ED-07 | ステータス更新ボタン群 | ボタン | PENDING/ONGOING/RESOLVED の3択 |
| ED-08 | 対応ログ入力欄 | テキストエリア | 追記専用・削除不可 |
| ED-09 | ログ保存ボタン | ボタン | 入力空の場合は無効 |
| ED-10 | 編集ボタン | ボタン | 起票者またはGL以上 |

### イベント
- ステータス更新ボタン押下
  1. `POST /api/v1/escalations/update` (statusのみ変更)
  2. 即時反映（画面再描画）
- ログ保存押下
  1. `POST /api/v1/escalations/log/add`
  2. タイムラインに追記（ログ入力欄クリア）
- 編集ボタン押下 → UI-05-2（編集モード）

### API連携
- `POST /api/v1/escalations/detail`
- `POST /api/v1/escalations/update`
- `POST /api/v1/escalations/log/add`

---

## 6. バリデーション
- 案件タイトル: 必須
- 対象メンバー氏名: 必須
- 所属チーム: 必須
- 対応ログ: 未入力の場合は保存ボタン無効

## 7. 業務制約
- 起票権限: TL以上のみ（REPORTER は不可）
- 対応ログの削除: 不可（追記のみ）
- ステータス遷移: `PENDING ↔ ONGOING ↔ RESOLVED`（双方向可）

## 8. メッセージ例
- 起票成功: 「エスカレーションを起票しました」
- ログ保存成功: 「対応ログを保存しました」
- 権限エラー: 「権限がありません」
