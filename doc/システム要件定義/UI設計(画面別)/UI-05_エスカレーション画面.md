# UI-05 エスカレーション管理画面

## 1. 画面概要

- 画面ID: UI-05
- 画面名: エスカレーション管理
- 目的: チーム・営業所内でのトラブル/案件を起票・管理し、対応履歴を追跡する
- アクセス可能ロール: **TL・GL・OM・SP・SM・SA**（NG・TM はアクセス不可）

### サブ画面構成

| サブID | 名称 | 概要 |
|---|---|---|
| UI-05-1 | エスカレーション一覧 | 可視範囲内の案件カード一覧 |
| UI-05-2 | エスカレーション作成/編集 | 新規起票・内容変更フォーム |
| UI-05-3 | エスカレーション詳細 | 詳細情報・履歴タイムライン・ログ追記 |

---

## 2. 入力項目

### UI-05-1 一覧フィルター

| 項目ID | 項目名 | 必須 | 形式 | 備考 |
|---|---|---|---|---|
| ES-F01 | ステータスフィルター | N | select | ALL / PENDING / ONGOING / RESOLVED |

### UI-05-2 作成/編集フォーム

| 項目ID | 項目名 | 必須 | 形式 | 備考 |
|---|---|---|---|---|
| EF-01 | 対象メンバー氏名 | Y | text | 自由入力 |
| EF-02 | 所属チーム | Y | 選択 | チームマスタより |
| EF-03 | 案件タイトル | Y | text | 最大200文字 |
| EF-04 | 重要度 | Y | select | LOW / MEDIUM / HIGH |
| EF-05 | ステータス | Y | select | PENDING / ONGOING / RESOLVED |
| EF-06 | 詳細内容 | N | textarea | 最大2000文字 |

### UI-05-3 対応ログ追記

| 項目ID | 項目名 | 必須 | 形式 | 備考 |
|---|---|---|---|---|
| EL-01 | 対応ログ内容 | Y（追記時） | textarea | 最大2000文字、削除不可 |

## 3. ボタン

| ボタンID | ボタン名 | 表示条件 | 動作 |
|---|---|---|---|
| ES-B01 | 新規起票 | TL以上 | UI-05-2（新規モード）へ |
| EF-B01 | 起票/保存 | - | 作成または更新 API 実行 |
| EF-B02 | キャンセル | - | 一覧へ戻る |
| ED-B01 | ステータス更新 | TL以上 | 即時 UPDATE 実行 |
| ED-B02 | ログ保存 | - | 対応ログ追記 API 実行（入力空の場合は無効） |
| ED-B03 | 編集 | 起票者または GL以上 | UI-05-2（編集モード）へ |

## 4. イベント

### UI-05-1 一覧

- **画面初期表示**: `POST /api/v1/escalations/search` でロール別スコープの一覧を取得する
- **新規起票押下** → UI-05-2（新規モード）
- **一覧カード押下** → UI-05-3

### UI-05-2 作成/編集

- **保存押下**
  1. 入力チェックを実行する
  2. 新規の場合: `POST /api/v1/escalations/create` を実行する
  3. 編集の場合: `POST /api/v1/escalations/update` を実行する
  4. 成功時トースト表示後、一覧へ遷移する

### UI-05-3 詳細

- **画面初期表示**: `POST /api/v1/escalations/detail` でデータを取得する
- **ステータス更新ボタン押下**: `POST /api/v1/escalations/update`（status のみ変更）→ 即時画面再描画
- **ログ保存押下**: `POST /api/v1/escalations/log/add` → タイムラインに追記（入力欄クリア）
- **編集ボタン押下** → UI-05-2（編集モード）

## 5. API連携

- `POST /api/v1/escalations/search`
- `POST /api/v1/escalations/detail`
- `POST /api/v1/escalations/create`
- `POST /api/v1/escalations/update`
- `POST /api/v1/escalations/log/add`

## 6. 入力チェック

| 項目 | ルール | エラーメッセージ |
|---|---|---|
| 案件タイトル | 必須、最大200文字 | 案件タイトルを入力してください |
| 対象メンバー氏名 | 必須 | 対象メンバー氏名を入力してください |
| 所属チーム | 必須 | 所属チームを選択してください |
| 重要度 | 必須 | 重要度を選択してください |
| ステータス | 必須 | ステータスを選択してください |
| 対応ログ内容 | 必須（追記時）、最大2000文字 | 対応ログを入力してください |

## 7. 画面制御

| 要素 | 表示/活性条件 |
|---|---|
| 画面全体 | NG・TM はアクセス不可（403 エラー） |
| 新規起票ボタン（UI-05-1） | TL以上のみ表示 |
| ステータス更新ボタン（UI-05-3） | TL以上のみ活性 |
| 編集ボタン（UI-05-3） | 起票者本人、または GL以上が表示 |
| ログ保存ボタン | 入力欄に内容ありの場合のみ活性 |
| 一覧スコープ | TL = 自チームの案件＋自分が起票したもの / GL = 自営業所全件 / OM = 全件 |
- ステータス遷移: `PENDING ↔ ONGOING ↔ RESOLVED`（双方向可）

## 8. メッセージ例

- 起票成功: 「エスカレーションを起票しました」
- ログ保存成功: 「対応ログを保存しました」
- 権限エラー: 「権限がありません」
