# UI-06 ユーザー管理画面

## 1. 画面概要

| 項目 | 内容 |
|---|---|
| 画面 ID | UI-06 |
| 画面名 | ユーザー管理画面 |
| 表示対象ロール | GL・OM・SP・SM・SA |
| URL（プロトタイプ） | `#user-management` |
| 概要 | ユーザーの一覧表示・新規登録・削除を行う画面。ロールに応じた操作スコープをサーバーで強制する。 |

---

## 2. 入力項目

### 2.1 検索フォーム

| 項目名 | 型 | 必須 | 説明 |
|---|---|---|---|
| キーワード | text | 任意 | 社員番号 / 氏名 で部分一致検索 |
| ロール | select | 任意 | ロール列挙値で絞り込み |
| 営業所 | select | 任意 | 営業所コードで絞り込み（SA/OM のみ表示） |

### 2.2 ユーザー登録フォーム

| 項目名 | 型 | 必須 | 説明 |
|---|---|---|---|
| 社員番号 | text | 必須 | 英数字、最大20文字、一意 |
| 氏名 | text | 必須 | - |
| ロール | select | 必須 | 登録可能ロールのみ選択肢に表示 |
| 営業所 | select | 必須 | - |
| チーム | select | 任意 | エンジニア（NG/TM）選択時は必須 |
| 初期パスワード | password | 必須 | 最大128文字 |

---

## 3. ボタン

| ボタン名 | 配置 | アクション |
|---|---|---|
| 検索 | 検索フォーム右端 | ユーザー一覧を再取得（API-17） |
| 登録 | 登録フォーム右端 | ユーザーを新規登録（API-18） |
| 削除 | 一覧行末尾 | 対象ユーザーを削除（API-19）。確認ダイアログを表示してから実行 |

---

## 4. イベント

| イベント | トリガー | 処理概要 |
|---|---|---|
| 画面初期表示 | mounted | ロール確認 → アクセス不可なら Dashboard へリダイレクト。ユーザー一覧を取得（API-17） |
| 検索実行 | 検索ボタンクリック | 検索条件を組み立てて API-17 を呼び出し、一覧を更新 |
| ページ変更 | ページネーション操作 | page パラメータを更新して API-17 を再呼び出し |
| 登録実行 | 登録ボタンクリック | 入力チェック → API-18 を呼び出し → 成功時はフォームをクリアして一覧を再取得 |
| 削除実行 | 削除ボタンクリック | 確認ダイアログ表示 → OK 時に API-19 を呼び出し → 成功時は一覧を再取得 |

---

## 5. API連携

| API ID | エンドポイント | 用途 |
|---|---|---|
| API-17 | `POST /api/v1/users/search` | ユーザー一覧取得 |
| API-18 | `POST /api/v1/users/create` | ユーザー登録 |
| API-19 | `POST /api/v1/users/delete` | ユーザー削除 |

---

## 6. 入力チェック

| 項目 | チェック内容 |
|---|---|
| 社員番号 | 必須・英数字・最大20文字 |
| 氏名 | 必須 |
| ロール | 必須・列挙値 |
| 営業所 | 必須 |
| チーム | エンジニア（NG/TM）の場合は必須 |
| 初期パスワード | 必須・最大128文字 |

---

## 7. 画面制御

| 制御対象 | 条件 | 制御内容 |
|---|---|---|
| ユーザー管理画面全体 | ロールが GL/OM/SP/SM/SA 以外 | 画面表示不可。ダッシュボードへリダイレクト |
| 営業所フィルター | ロールが GL | 非表示（自グループ固定） |
| 削除ボタン | 対象ユーザーがログインユーザー自身 | 非表示（自分自身は削除不可） |
| 登録可能ロール選択肢 | GL の場合 | NG/TM（エンジニア）のみに制限 |
| 登録可能ロール選択肢 | SP/SM の場合 | NG/TM/SP/SM のみに制限 |
| チームセレクトボックス | ロール選択が NG/TM 以外 | 非表示 |
