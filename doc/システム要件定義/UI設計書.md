# 月報管理システム UI設計書

## 1. 目的
本書は、`doc/プロトタイプデザイン.html` の画面デザイン・操作挙動を基に、実装向けUI仕様を定義する。

## 2. 適用範囲
- 対象クライアント: Webブラウザ
- 対象画面:
- ログイン画面
- ダッシュボード(月報一覧)画面
- 月報作成/編集画面
- 月報詳細画面
- ロール別表示/操作制御

## 3. 画面遷移
| 遷移元 | 操作 | 遷移先 | 備考 |
|---|---|---|---|
| ログイン画面 | ログイン成功 | ダッシュボード | トークン/ユーザー情報を保持 |
| ログイン画面 | ログイン失敗 | ログイン画面 | エラーメッセージ表示 |
| ダッシュボード | 新規提出 | 月報作成画面 | 新規モード |
| ダッシュボード | カード選択 | 月報詳細画面 | reportIdで詳細取得 |
| 月報詳細 | 編集 | 月報編集画面 | 作成者本人のみ |
| 月報作成/編集 | 保存 | ダッシュボード | 成功トースト表示 |
| 月報詳細 | 回答公開 | 月報詳細(再表示) | TL以上かつ他者月報 |
| 月報詳細 | 削除 | ダッシュボード | 作成者本人またはOM |

## 4. 画面仕様

## 4.1 ログイン画面
### 表示項目
| 項目ID | 項目名 | 種別 | 必須 | 備考 |
|---|---|---|---|---|
| LG-01 | 社員番号 | テキスト | Y | 半角英数 |
| LG-02 | パスワード | パスワード | Y | マスク表示 |
| LG-03 | ログインボタン | ボタン | - | 押下で認証API呼出 |
| LG-04 | エラーメッセージ | ラベル | - | 認証失敗時表示 |

### 入力チェック
- 社員番号: 未入力不可、英数字のみ
- パスワード: 未入力不可

### API連携
- `POST /api/v1/auth/login`

## 4.2 ダッシュボード(月報一覧)画面
### 表示項目
| 項目ID | 項目名 | 種別 | 備考 |
|---|---|---|---|
| DB-01 | ユーザー名/社員番号 | ラベル | ヘッダ表示 |
| DB-02 | 所属/ロール | ラベル | ヘッダ表示 |
| DB-03 | 新規提出ボタン | ボタン | 月報作成へ遷移 |
| DB-04 | 管理内全提出数 | KPIカード | TL以上表示 |
| DB-05 | 未回答報告数 | KPIカード | TL以上表示 |
| DB-06 | 月報カード一覧 | リスト | month降順 |
| DB-07 | 回答ステータス | バッジ | Checked/Waiting |

### 表示制御(ロール)
- REPORTER: 自分の月報のみ表示
- TL: 自分 + 同一チームの月報表示
- GL: 自分 + 同一営業所の月報表示
- OM: 全件表示

### API連携
- `POST /api/v1/dashboard/summary`
- `POST /api/v1/reports/search`

## 4.3 月報作成/編集画面
### 表示項目
| 項目ID | 項目名 | 種別 | 必須 | 備考 |
|---|---|---|---|---|
| RP-01 | 報告月 | 年月 | Y | `yyyy-MM` |
| RP-02 | タイトル | テキスト | Y | 最大100文字 |
| RP-03 | 営業情報 | テキストエリア | N | 任意入力 |
| RP-04 | 来月残業見込み(時間) | 数値 | N | 0-300 |
| RP-05 | 来月残業理由 | テキスト | N | 最大255文字 |
| RP-06 | 今月残業見込み(時間) | 数値 | N | 0-300 |
| RP-07 | 今月残業理由 | テキスト | N | 最大255文字 |
| RP-08 | コンディション7項目 | 3値選択 | Y | `○/△/×` |
| RP-09 | コメント | テキストエリア | N | 任意入力 |
| RP-10 | 提出ボタン | ボタン | - | タイトル未入力時無効 |
| RP-11 | キャンセルボタン | ボタン | - | 一覧へ戻る |

### API連携
- 新規: `POST /api/v1/reports/create`
- 更新: `POST /api/v1/reports/update`

## 4.4 月報詳細画面
### 表示項目
| 項目ID | 項目名 | 種別 | 備考 |
|---|---|---|---|
| DT-01 | 月報ヘッダ(月/営業所/チーム) | ラベル | report情報 |
| DT-02 | 本文(営業情報/残業/診断/コメント) | 表示領域 | report情報 |
| DT-03 | 編集ボタン | ボタン | 作成者本人のみ |
| DT-04 | 削除ボタン | ボタン | 作成者本人 or OM |
| DT-05 | 回答入力欄 | テキストエリア | TL以上かつ他者月報 |
| DT-06 | 回答公開ボタン | ボタン | 条件一致時のみ有効 |
| DT-07 | 回答表示欄 | 表示領域 | 全ロール表示 |

### API連携
- 詳細取得: `POST /api/v1/reports/detail`
- 回答更新: `POST /api/v1/reports/feedback/update`
- 削除: `POST /api/v1/reports/delete`

## 5. UI共通仕様

## 5.1 通知
- 成功時: トースト表示(例: 提出しました、更新しました)
- 失敗時: エラーメッセージ表示(API `resultMsg`)

## 5.2 ローディング
- API通信中はローディング表示
- 二重送信防止のため主要ボタンを一時無効化

## 5.3 コンディション値変換
- UI値: `○/△/×`
- API送信値: `OK/WARN/NG`
- 受信時は逆変換して表示

## 5.4 レスポンシブ
- PC: 3カラムカード表示(一覧)
- タブレット: 2カラム
- スマホ: 1カラム

## 6. バリデーション/業務ルール
- 同一ユーザーの同一月報は1件まで(削除フラグ有効データ内)
- 作成者以外は月報を編集不可
- TL以上でも自分の月報へ回答不可
- 未回答件数は「自分以外」かつ「回答未登録」を集計

## 7. アクセシビリティ/操作性
- 主要操作ボタンは視認しやすい色コントラストを維持
- 入力エラーは項目単位で明示
- キーボード操作でフォーカス遷移可能
