## 1 基本情報

- API ID: API-22
- 名称: グループ削除
- Method/URI: `POST /api/v1/groups/delete`
- 認証: 必須
- アクセス可能ロール: **OM・SA のみ**（GL はグループ削除不可、それ以外は 403）

## 2 概要

指定したグループを削除する。GL はグループ自体の削除はできない。

## 3 前提条件

- 認証済み JWT が有効であること。
- ログインユーザーのロールが OM または SA であること。

## 4 入出力仕様

### 4.1 Request

```json
{
  "groupCode": "GROUP_B"
}
```

### 4.2 Request バリデーション

| 項目 | 必須 | ルール |
|---|---|---|
| groupCode | 必須 | 既存グループコード |

### 4.3 Response(params)

```json
{
  "deleted": true,
  "groupCode": "GROUP_B"
}
```

## 5 ロジックフロー

1. JWT からログインユーザーのロール/所属を取得する。
2. ロールを確認する。
   - OM・SA 以外の場合は、以下の処理を実行する。
     - `AUTH_403` を返す。
   - OM・SA の場合は、以下の処理を実行する。
     - 次のステップに進む。
3. 削除対象グループが存在するか確認する。
   - 存在しない場合は、以下の処理を実行する。
     - `GROUP_404` を返す。
   - 存在する場合は、以下の処理を実行する。
     - 次のステップに進む。
4. OM の場合は、以下の処理を実行する。
   - 削除対象グループが自営業所配下であることを確認する。
   - スコープ外の場合は `AUTH_403` を返す。
5. `groups` テーブルから DELETE（または論理削除）する。
6. `deleted: true` と `groupCode` を返却する。

## 6 例外ケース

| ケース | エラーコード | 説明 |
|---|---|---|
| 未認証 | `AUTH_001` | ログインしてください |
| 権限不足 | `AUTH_403` | 権限がありません |
| グループ未存在 | `GROUP_404` | グループが存在しません |

## 7 CRUD

| テーブル | 操作 |
|---|---|
| groups | SELECT（存在確認） / DELETE |
