## 1 基本情報

- API ID: API-23
- 名称: チーム一覧検索
- Method/URI: `POST /api/v1/teams/search`
- 認証: 必須
- アクセス可能ロール: **GL・OM・SA のみ**（それ以外は 403）

## 2 概要

チーム一覧を検索して返却する。ロールに応じた表示スコープをサーバーで強制する。

## 3 前提条件

- 認証済み JWT が有効であること。
- ログインユーザーのロールが GL・OM・SA いずれかであること。

## 4 入出力仕様

### 4.1 Request

```json
{
  "groupCode": "GROUP_A",
  "teamName": "",
  "page": 1,
  "size": 20
}
```

### 4.2 Request バリデーション

| 項目 | 必須 | ルール |
|---|---|---|
| groupCode | 任意 | 既存グループコード |
| teamName | 任意 | 部分一致検索 |
| page | 任意 | デフォルト 1 |
| size | 任意 | デフォルト 20、最大 100 |

### 4.3 Response(params)

```json
{
  "teams": [
    {
      "teamCode": "TEAM_A",
      "teamName": "Aチーム",
      "groupCode": "GROUP_A",
      "groupName": "東京第1グループ",
      "tlUserId": 1003,
      "tlUserName": "鈴木 一郎",
      "memberCount": 4
    }
  ],
  "totalCount": 3,
  "page": 1,
  "size": 20
}
```

## 5 ロジックフロー

1. JWT からログインユーザーのロール/所属を取得する。
2. ロールを確認する。
   - GL・OM・SA 以外の場合は、以下の処理を実行する。
     - `AUTH_403` を返す。
   - GL・OM・SA の場合は、以下の処理を実行する。
     - 次のステップに進む。
3. ロール別スコープを決定する。
   - GL の場合は、以下の処理を実行する。
     - 自グループ配下のチームのみを対象とする。
   - OM の場合は、以下の処理を実行する。
     - 自営業所配下の全チームを対象とする。
   - SA の場合は、以下の処理を実行する。
     - 全チームを対象とする。
4. Request のフィールドでフィルタリングする（teamName は部分一致）。
5. ページネーションを適用する。
6. チーム情報（TL 名・メンバー数含む）を組み立てて返却する。

## 6 例外ケース

| ケース | エラーコード | 説明 |
|---|---|---|
| 未認証 | `AUTH_001` | ログインしてください |
| 権限不足 | `AUTH_403` | 権限がありません |
