## 1 基本情報

- API ID: API-25
- 名称: チーム削除
- Method/URI: `POST /api/v1/teams/delete`
- 認証: 必須
- アクセス可能ロール: **GL・OM・SA のみ**（それ以外は 403）

## 2 概要

指定したチームを削除する。

## 3 前提条件

- 認証済み JWT が有効であること。
- ログインユーザーのロールが GL・OM・SA いずれかであること。

## 4 入出力仕様

### 4.1 Request

```json
{
  "teamCode": "TEAM_D"
}
```

### 4.2 Request バリデーション

| 項目 | 必須 | ルール |
|---|---|---|
| teamCode | 必須 | 既存チームコード |

### 4.3 Response(params)

```json
{
  "deleted": true,
  "teamCode": "TEAM_D"
}
```

## 5 ロジックフロー

1. JWT からログインユーザーのロール/所属を取得する。
2. ロールを確認する。
   - GL・OM・SA 以外の場合は、以下の処理を実行する。
     - `AUTH_403` を返す。
   - GL・OM・SA の場合は、以下の処理を実行する。
     - 次のステップに進む。
3. 削除対象チームが存在するか確認する。
   - 存在しない場合は、以下の処理を実行する。
     - `TEAM_404` を返す。
   - 存在する場合は、以下の処理を実行する。
     - 次のステップに進む。
4. ロール別スコープを確認する。
   - GL の場合は、以下の処理を実行する。
     - 削除対象チームが自グループ配下であることを確認する。
   - OM の場合は、以下の処理を実行する。
     - 削除対象チームが自営業所配下であることを確認する。
   - SA の場合は、以下の処理を実行する。
     - 全スコープを許可する。
5. スコープ外の場合は、以下の処理を実行する。
   - `AUTH_403` を返す。
6. `teams` テーブルから DELETE（または論理削除）する。
7. `deleted: true` と `teamCode` を返却する。

## 6 例外ケース

| ケース | エラーコード | 説明 |
|---|---|---|
| 未認証 | `AUTH_001` | ログインしてください |
| 権限不足 | `AUTH_403` | 権限がありません |
| チーム未存在 | `TEAM_404` | チームが存在しません |

## 7 CRUD

| テーブル | 操作 |
|---|---|
| teams | SELECT（存在確認） / DELETE |
