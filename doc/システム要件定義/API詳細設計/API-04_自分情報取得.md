## 1 基本情報

- API ID: API-04
- 名称: 自分情報取得
- Method/URI: `POST /api/v1/users/me`
- 認証: 必須
- アクセス可能ロール: **全ロール**（認証済みユーザー）

## 2 概要

ログインユーザーのプロフィール情報を返却する。

## 3 前提条件

- 認証済み JWT が有効であること。

## 4 入出力仕様

### 4.1 Request

```json
{}
```

### 4.2 Request バリデーション

| 項目 | 必須 | ルール |
|---|---|---|
| （リクエストボディなし） | - | - |

### 4.3 Response(params)

```json
{
  "userId": 1004,
  "employeeNo": "EMP004",
  "name": "山田 健太",
  "role": "TM",
  "officeCode": "TOKYO",
  "teamCode": "TEAM_A"
}
```

## 5 ロジックフロー

1. JWT からログインユーザーの ID を特定する。
2. `users` テーブルを参照し `delete_flag=0` を確認する。
   - ユーザーが存在しない場合は、以下の処理を実行する。
     - `USER_404` を返す。
   - ユーザーが存在する場合は、以下の処理を実行する。
     - 次のステップに進む。
3. ユーザーの基本情報を DTO に整形して返却する。

## 6 例外ケース

| ケース | エラーコード | 説明 |
|---|---|---|
| 未認証 | `AUTH_001` | ログインしてください |
| ユーザー情報なし | `USER_404` | ユーザー情報が見つかりません |
