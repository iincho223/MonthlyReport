## 1 基本情報

- API ID: API-10
- 名称: 月報削除
- Method/URI: `POST /api/v1/reports/delete`
- 認証: 必須
- アクセス可能ロール: **作成者本人、または OM**

## 2 概要

月報を論理削除する（`delete_flag=1`）。作成者本人または OM のみ実行可。

## 3 前提条件

- 認証済み JWT が有効であること。
- 対象月報が作成者本人、またはログインユーザーが OM であること。

## 4 入出力仕様

### 4.1 Request

```json
{
  "reportId": "01HXYZ..."
}
```

### 4.2 Request バリデーション

| 項目 | 必須 | ルール |
|---|---|---|
| reportId | 必須 | - |

### 4.3 Response(params)

```json
{
  "reportId": "01HXYZ...",
  "deleted": true
}
```

## 5 ロジックフロー

1. JWT からログインユーザーの情報を取得する。
2. `reportId` で `reports` テーブルを検索する。
   - 存在しない場合は、以下の処理を実行する。
     - `REPORT_404` を返す。
   - 存在する場合は、以下の処理を実行する。
     - 次のステップに進む。
3. 削除権限を確認する。
   - 作成者本人、または OM の場合は、以下の処理を実行する。
     - 次のステップに進む。
   - 権限不足の場合は、以下の処理を実行する。
     - `AUTH_403` を返す。
4. `reports` テーブルを論理削除する（`delete_flag=1`）。
5. 関連する `report_conditions` / `report_feedbacks` も論理削除する。

## 6 例外ケース

| ケース | エラーコード | 説明 |
|---|---|---|
| 未認証 | `AUTH_001` | ログインしてください |
| 削除権限なし | `AUTH_403` | 削除権限がありません |
| 対象なし | `REPORT_404` | 対象の月報が存在しません |

## 7 CRUD

| テーブル | 操作 |
|---|---|
| reports | SELECT / UPDATE（論理削除） |
| report_conditions | UPDATE（論理削除） |
| report_feedbacks | UPDATE（論理削除） |
