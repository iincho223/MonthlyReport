# API-03 ログアウト

## 1. 基本情報

- API ID: API-03
- 名称: ログアウト
- Method/URI: `POST /api/v1/auth/logout`
- 認証: 必須

## 2. 目的

ログイン中ユーザーのセッションを終了し、利用中トークンを無効化する。

## 3. リクエスト

```json
{}
```

## 4. 正常レスポンス(params)

```json
{
  "success": true
}
```

## 5. エラー

- `AUTH_001`: 未認証
- `SYS_500`: システムエラー

## 6. 主処理

1. JWTからユーザーを特定
2. 該当ユーザーの有効な `refresh_tokens` を失効
3. 監査ログ出力
