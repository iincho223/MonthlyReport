## 1 基本情報

- API ID: API-03
- 名称: ログアウト
- Method/URI: `POST /api/v1/auth/logout`
- 認証: 必須
- アクセス可能ロール: **全ロール**（認証済みユーザー）

## 2 概要

ログイン中ユーザーのセッションを終了し、利用中のリフレッシュトークンを無効化する。

## 3 前提条件

- 認証済み JWT が有効であること。

## 4 入出力仕様

### 4.1 Request

```json
{}
```

### 4.2 Request バリデーション

| 項目 | 必須 | ルール |
|---|---|---|
| （リクエストボディなし） | - | - |

### 4.3 Response(params)

```json
{
  "success": true
}
```

## 5 ロジックフロー

1. JWT からログインユーザーを特定する。
2. `refresh_tokens` テーブルから該当ユーザーの有効なトークンを検索する。
3. 対象トークンに `revoked_at` を設定して失効させる。
4. `success: true` を返却する。

## 6 例外ケース

| ケース | エラーコード | 説明 |
|---|---|---|
| 未認証 | `AUTH_001` | ログインしてください |
| システムエラー | `SYS_500` | システムエラーが発生しました |
